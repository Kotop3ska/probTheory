# Анализ собственного распределения sin(x/2) с применением методов теории вероятностей

## 📁 О распределении

Собственное **непрерывное распределение** определено на интервале **[0, π]** с плотностью вероятности **$\phi(x) = \sin(\frac{x}{2})$**.  
Наследуется от `scipy.stats.rv_continuous` и реализовано в классе `CustomDistribution`.  
**Параметры**: `a = 0`, `b = π ≈ 3.1416`.

### 📊 Формулы распределения

**Плотность вероятности (PDF)**:


$$
\phi(x) = \begin{cases} 
\sin\left(\frac{x}{2}\right), & x \in [0, \pi] \\
0, & \text{иначе}
\end{cases}
$$

**Функция распределения (CDF)**:

$$
F(x) = \begin{cases} 
0, & x \le 0 \\
1 - \cos\left(\frac{x}{2}\right), & 0 < x \le \pi \\
1, & x > \pi 
\end{cases}
$$
